## 二、技术演变总路线（四层能力）

> 核心命题：单图浅 3D 不是单一模型问题，而是深度、表示、显露和部署的四层接力。

```text
L1 深度先验（并行，非代际替换）
├─ Depth Anything V2：相对深度、泛化、边界质量
├─ Depth Pro：零样本度量深度、绝对尺度、清晰边界
└─ SHARP：以 Depth Pro 为骨干，微调输出双层视差/深度
   共同问题：遮挡边界、细结构、反射透明表面不可靠

L2 场景表示 ★本研究重点
├─ 分层图像路线（轻量、规整）
│   ├─ 第零代：单层深度 Warp（空洞、拉伸、无隐藏背景）
│   ├─ 3D Photography：LDI + 显式连接 + RGB-D 联合补全
│   ├─ SLIDE：软分层 + Matting（硬分层 → 软分层）
│   └─ 全局 MPI 的并行改进方向
│       ├─ MINE：连续深度 MPI + NeRF 思想（固定平面 → 连续查询）
│       ├─ AdaMPI：自适应调整全局平面位置
│       └─ TMPI：局部分块，每块自适应选择少量平面
└─ 前馈 3DGS 家族（非线性继承，不同输入条件）
    ├─ Splatter Image：单图对象、逐像素高斯
    ├─ pixelSplat：双图场景、已知位姿
    ├─ AnySplat：非标定多图、同时预测相机和高斯
    ├─ Flash3D：单图场景 + 预训练深度
    └─ SHARP：单图场景 + 双层深度 + Base/Delta ★基线

L3 显露区域处理 ★本研究重点（纵向演进，横跨两路线）
直接Warp → LDI局部补全 → SLIDE深度感知补全
→ TMPI隐藏RGBA层+精炼 → SHARP第二层高斯隐式解释
→ 当前Framework：显式检测并补充显露高斯

L4 工程化与部署（横向工程线，非下一代）
抗混叠/稳定渲染（AAA/EVER/StochasticSplats）
→ 贡献度剪枝/合并/量化/结构化编码（LightGaussian/HAC++/...）
→ Metal/Vulkan/OpenGL ES/WebGPU 移动端渲染（Mobile-GS/SEELE/...）
→ 必要时蒸馏为 TMPI/Soft-LDI/Mesh
⚠️ 这些方法在多视图优化3DGS上的结论，不能直接外推到SHARP前馈高斯，需本地重验
```

**底部落点**：Benchmark 证明 SHARP 可作为附近视角冻结基线；下一步重点是 L2 表示与 L3 显露区域。

## 三、PPT 大纲（R1–R5 逐页）

### R1｜单图浅 3D 需要四层能力共同成立

- **标题（结论句）**：单图浅 3D 不是单一模型问题，而是深度、表示、显露和部署的四层接力
- **主体**：L1–L4 纵向四层流程图（见上方总路线图）
- **底部落点**：Benchmark 证明 SHARP 可作为附近视角冻结基线；下一步重点是 L2 表示与 L3 显露区域
- **注意**：不重复 0.04 / 3% / keep100（前面已讲）
- **视觉**：纵向四层流程图，L2/L3 标★，可注明"本研究跨 L2–L4，重点 L2/L3"

### R2｜路线一：分层图像（补出隐藏背景 → 软边界与局部自适应）

- **标题**：分层图像从"补出隐藏背景"逐步演进到"软边界和局部自适应"
- **双分支时间线**：

```text
分支一：硬边界与补全
单层深度Warp（空洞、拉伸）
→ 3D Photography（LDI + 显式连接 + RGB-D补全）
→ SLIDE（软分层 + Matting，保护头发和软边界）

分支二：表示冗余与离散化
全局MPI（典型基线常使用32层，深度离散且冗余）
├─ MINE（用NeRF思想把固定平面推广到连续深度查询）
├─ AdaMPI（自适应调整全局平面位置）
└─ TMPI（把全局MPI拆成局部块，每块自适应选择少量平面）
```

- **右侧突出 TMPI**（刚精读，素材现成）：
  - 局部深度复杂度低
  - 主配置每块 4 层
  - 置信度加权 K-means
  - 代价：跨块细结构可能不一致
- **视觉**：双分支时间线，右侧优先放 TMPI 论文 Figure 1 方法概览或 Figure 3 分块表示，制作前根据页面实际内容确认；两个分支前各加一行小注说明各自解决什么问题

### R3｜路线二：前馈 3DGS（生成从逐场景优化压缩为一次前向）

- **标题**：SHARP 是目前与本课题输入条件最匹配的单图场景基线（不说"场景级终点"）
- **家族树**：

```text
3DGS：多图 + 位姿 + 逐场景优化
↓
前馈3DGS家族（非线性继承）
├─ Splatter Image：单图对象、逐像素高斯
├─ pixelSplat：双图场景
├─ AnySplat：非标定多图场景
├─ Flash3D：单图场景 + 深度先验
└─ SHARP：单图场景 + 双层深度 + Base/Delta ★
```

- **强调**：这些方法不是逐代替代关系，而是在对象/场景、单图/多图、已知/未知相机等不同输入条件下探索前馈高斯
- **SHARP 适合做基线的三条理由**：
  - 单张普通场景照片
  - 官方代码和权重可复现
  - 输出显式 3DGS，可直接测试附近视角和工程性能
- **视觉**：前馈 3DGS 家族树

### R4｜两条路线对比：TMPI vs SHARP（表示哲学对比）

- **标题**：TMPI 与 SHARP 代表两种不同的表示哲学
- **对比表（5 维度）**：

| 维度 | TMPI | SHARP |
|---|---|---|
| 表示 | 分块 RGBA 平面 | 连续 3D 高斯 |
| 自适应 | 局部选择平面深度 | 网络修正高斯属性 |
| 显露处理 | 隐藏 RGBA 层与精炼 | 第二层高斯隐式学习 |
| 工程特征 | 规整、易走纹理管线 | 表达灵活、表示较重 |
| 主要风险 | 跨块细结构不一致 | 细结构错位、生成与内存成本 |

- **数据口径放页脚**（不占主表）：
  > TMPI 论文报告 5.25MB@350×630；本地 SHARP 完整 PLY 约 63MiB。分辨率、字段和序列化方式不同，不直接计算压缩倍数。
- **混合路线（底部）**：

```text
高质量生成：3DGS
+ 显露处理：借鉴分层与置信度
+ 最终部署：压缩3DGS或蒸馏为轻量表示
```

- **核心传达**：比较两条路线，寻找可融合的能力（不是二选一）
- **视觉**：左右对比表，中间不用复杂插图

### R5｜仍未闭合的问题 → 我们的位置

- **标题**：现有方法仍未闭合 30°、显露一致性和移动端证据
- **缺口表**：

| 尚未闭合的问题 | 当前证据边界 |
|---|---|
| 30° 下 DISTS < 0.06 | SHARP 报告 DISTS，但不是在统一 30° 角度协议下；本地 Benchmark 也尚未测试 30° |
| 显露内容跨视角一致 | TMPI 存在跨块细结构风险；本地 SHARP 有 3/13 轻微细结构错位，缺少 30° 显露区专项评价 |
| Mate 80 Pro 上的 <5s / <3GB | 当前 SHARP 双硬件结果未达标；尚未完成目标手机上的完整生成与渲染验证 |

- **底部衔接**：
  > Benchmark 回答了"SHARP 作为附近视角基线是否可靠"；下一轮要回答"加入显露补全后，能否扩展到 5°/15°/30°"。

- **视觉**：三个缺口横向排列，底部箭头指向现有自研实验页

## 四、关键口径边界（制作 PPT 时必须遵守）

1. **TMPI vs SHARP 大小**：5.25MB@350×630 vs 本地 63MiB PLY，口径不同，不直接计算倍数。
2. **效率数字**：TMPI 91.6ms / 3.20GB / 5.25MB 均不含 DPT 单目深度估计；DPT 单列 31ms / 4.39GB。只在 RTX 3080 上测得，不代表手机速度。
3. **DISTS**：SHARP 论文报告了 DISTS（Scannet 0.067），只是没在统一 30° 协议下证明 <0.06。不能写"论文无 DISTS"。
4. **SHARP 细结构**：3D 高斯理论上更灵活（连续非规则原语），但本地 SHARP 仍有轻微细结构错位，不能写成"强于所有分层方法"。
5. **SHARP 依赖 CUDA**：官方实现依赖 CUDA/gsplat，但 3DGS 表示本身可用 Metal/Vulkan/WebGPU 另行实现。
6. **SHARP 第二层补全**：第二层高斯通过新视角损失隐式学习潜在遮挡内容，没有独立显露区域检测或显式图像补全模块。
7. **SHARP 反射**：反射/透明/视角相关外观仍是理论风险；本地 Benchmark 未观察到严重反射失败，不能写成"所有反射场景都会出错"。
8. **TMPI 每块 4 层**：主配置使用 4 层，是论文的工程折中，不是所有场景的理论最优层数。
9. **压缩方法边界**：LightGaussian / HAC++ / Mobile-GS 等多视图优化 3DGS 上的结论，不能直接外推到 SHARP 前馈高斯，需本地重验。
10. **SLIDE 无官方代码**：官方项目页仅提供论文、补充材料、视频和结果，无代码入口，无法本地复现。
