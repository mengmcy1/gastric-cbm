# 第二批数据预处理冻结参数 v1

> 冻结日期：2026-07-21  
> 适用数据：`数据/第二批整理后/dataset_manifest.csv`  
> 适用路线：完全弱标注 `matched_weak_v1`  
> 变更规则：调试验收失败时不得原地改值，必须记录原因并升级为 v1.1。

## 1. 视野检测与裁剪

| 参数 | 冻结值 | 说明 |
| --- | ---: | --- |
| 检测最长边 | 512 px | 仅用于 ROI 检测，坐标映射回原图 |
| 灰度前景阈值 | 10 / 255 | 分离近黑边框与有效视野 |
| 高斯预平滑 | 5x5 | 降低 JPEG 噪点影响 |
| 闭运算核 | 检测图短边的 2%，取最近奇数且至少 5 px | 连接被暗区分开的胃镜视野 |
| 连通区域选择 | 与中心 50% 窗口相交的最大外轮廓 | 避免黑边上的文字成为裁剪主体 |
| 最小轮廓面积比 | 0.25 | 低于该值视为检测失败 |
| 最小宽/高比 | 原图宽、高的 0.45 | 防止误选局部高亮区域 |
| 中心偏移上限 | 图像对角线的 0.20 | 轮廓中心偏移过大则回退 |
| ROI 内缩 | 检测框短边的 1.5% | 仅在检测到明显外边框时应用 |
| 全幅判定 | ROI 四边距均小于对应边长的 1% | 判为无明显黑边，不额外内缩 |
| 检测失败回退 | 使用全图，`crop_status=fallback_full_frame` | 不静默删除，交由调试汇总检查 |

处理边界：只去除黑边、外框及视野外区域；保留视野内器械、气泡、黏液、反光和血液。v1 不使用设备模板，不做 OCR 或文字擦除。

## 2. 输出图像

| 参数 | 冻结值 |
| --- | ---: |
| 输出尺寸 | 512x512 |
| 缩小插值 | OpenCV `INTER_AREA` |
| 放大插值 | OpenCV `INTER_CUBIC` |
| 输出格式 | JPEG |
| JPEG 质量 | 95 |
| 色彩空间 | RGB，3 通道 |
| 原始数据 | 只读，不覆盖 |

输出保留原目录层级。训练阶段再从 512x512 统一变换为 224x224。

## 3. 自动质量与患者限图

| 参数 | 冻结值 | 说明 |
| --- | ---: | --- |
| 质量评估尺寸 | 224x224 | 在裁剪后有效 ROI 上统一计算 |
| 清晰度指标 | 灰度图 Laplacian variance | 仅用于患者内排序 |
| 全局模糊硬阈值 | 不启用 | 避免按设备/标签不对称误删 |
| 感知去重 | 64-bit dHash | 不依赖 scikit-image |
| 近重复阈值 | Hamming distance <= 4 | 同一患者内判为同一重复组 |
| 每患者最多图片数 | 3 |
| 每患者最少图片数 | 1（存在可处理图时） |
| 可解析时间戳最小间隔 | 2 秒 | 候选充足时使用，不足时自动放宽 |
| 随机种子 | 42 |

自动选择顺序固定为：

1. 排除损坏或无法解码图像；裁剪失败图保留但标记。
2. 在患者内按 dHash 合并近重复图，重复组代表图取清晰度最高者。
3. 第一张选择清晰度最高的代表图。
4. 后续图片优先最大化与已选图片的最小 dHash 距离，清晰度作为并列决胜条件。
5. 最多选择 3 张，不足 3 张不补；不读取模型概率、Grad-CAM 或测试结果。

弱标注限制：癌患者的入选图不保证病灶逐图可见，统一记录 `review_status=pending`。

## 4. 弱标注匹配

| 参数 | 冻结值 |
| --- | ---: |
| 主方案 | 患者级 1:1 匹配 |
| 敏感性分析 | 患者级 1:2 匹配 |
| 匹配层级 | 中心 -> 自动设备/画面风格 -> 相近年份 |
| 年份容差初值 | +/- 2 年；无年份时标记 missing，不跨中心猜测 |
| 患者重复使用 | 禁止 |
| 随机种子 | 42 |
| 未匹配可用样本 | 进入 `usable_unmatched`；保留于 full，不进入 matched |

设备/画面风格分组的最终规则在完成裁剪后根据 manifest 统计冻结，不使用标签结果或模型输出调组。

## 5. 训练阶段分辨率破坏增强

以下增强只应用于训练集，癌与非癌使用完全相同的概率和范围；验证、测试及外部验证均不使用随机破坏。

| 增强 | 概率 | 冻结范围 |
| --- | ---: | --- |
| 随机降采样后升采样 | 0.50 | 中间边长均匀采样 144～224，再恢复 224x224 |
| JPEG 压缩 | 0.30 | 质量均匀采样 70～95 |
| 高斯模糊 | 0.20 | 3x3 核，sigma 0.1～0.8 |

正式训练前必须生成增强前后对照图，确认细微黏膜结构未被系统性抹除。若需要修改范围，升级参数版本并重新生成全部对应结果。

## 6. 调试验收门槛

- 每个主要中心、标签和高频原始分辨率至少抽查 10 张；稀有分组全部或最多 10 张。
- 调试集必须同时覆盖圆形、八角形、矩形/全幅视野及带边缘文字样本。
- 不允许出现有效视野或疑似病灶被明显截断。
- `fallback_full_frame`、异常小 ROI、异常中心偏移必须单独汇总。
- 任一主要分组裁剪失败率超过 5%，暂停全量处理并升级参数版本。
- 癌/非癌或不同中心之间的失败率差超过 5 个百分点，暂停并排查不对称处理。

## 7. 全量验收补充（2026-07-22）

- 全量验收的裁剪框面积硬门槛设为原图的 45%；低于 60% 仍作为警告进入肉眼复核。
