> 冻结日期：2026-07-22  
> 训练入口：`程序/模型训练/正式代码/*_train_debiased.py`  
> 共享模块：`程序/模型训练/正式代码/train_utils.py`  
> GPU：`CUDA_VISIBLE_DEVICES=1`

## 1. 冻结数据清单

目录：`数据整理记录/第二批/训练划分_v1`

- `full_split_seed42.csv`：患者级固定 70/15/15，实验 A。
- `relaxed_all_cases_1to1_split_seed42.csv`：匹配组级固定 70/15/15，实验 B。
- `relaxed_all_cases_1to2_split_seed42.csv`：匹配组级固定 70/15/15，实验 D。
- `strict_common_support_1to1_folds5_seed42.csv`：严格集 5 折，实验 C；指定测试折 `k`，下一折 `(k+1) mod 5` 为验证，其余三折训练。

训练脚本只接受包含 `split` 或 `fold` 的冻结清单，不允许在训练时临时随机拆分。患者、processed SHA-256 和匹配组跨集合检查均已通过。

## 2. 共同输入与增强

- 裁剪母版：`数据/第二批裁剪后_v1_1`，512x512 高质量 JPG。
- 模型输入：224x224。
- 验证/测试：仅 resize、ImageNet 归一化，不做随机增强。
- 训练集基础增强：保守随机裁剪 `scale=0.85-1.0, ratio=0.9-1.1`、水平翻转、±10度旋转、轻度颜色扰动。
- 随机降采样再升采样：概率 0.5，缩放比例 0.50-0.85。
- 随机 JPEG：概率 0.5，质量 60-95。
- 轻微高斯模糊：概率 0.3，sigma 0.1-1.2。

癌与非癌使用相同参数范围。24 张风险样本、每张 3 个随机版本的联系图已生成；内部检查未见系统性裁掉胃镜主体，癌图中的黏膜异常仍可辨认。

## 3. 训练参数

| 参数 | ResNet50 | EfficientNet-B0 |
| --- | ---: | ---: |
| ImageNet 权重 | IMAGENET1K_V2 | IMAGENET1K_V1 |
| Batch size | 32 | 32 |
| S1 | 仅分类头，10 epochs，LR 1e-3 | 仅分类头，10 epochs，LR 1e-3 |
| S2 | layer4 + fc，20 epochs，LR 1e-4 | features[5:] + classifier，20 epochs，LR 1e-4 |
| 优化器 | AdamW | AdamW |
| Weight decay | 1e-4 | 1e-4 |
| S2 scheduler | CosineAnnealing | CosineAnnealing |
| Early stop | 8 | 8 |
| Label smoothing | 0.05 | 0.10 |
| 随机种子 | 42 | 42 |

类别权重只根据当前训练 split 的图片标签动态计算。S1 与 S2 分别保存最佳验证 AUC 状态；只有 S2 严格优于 S1 时才使用 S2，否则回退到更保守的 S1。

## 4. 评估与输出

每次运行输出：

- 图片级和患者级验证/测试预测及 AUC、Accuracy、Sensitivity、Specificity、Precision、F1、CM。
- 按中心、年份、style_group、size_group、frame_profile 分层的图片级和患者级指标。
- `training_history.csv`、实际 split 快照、训练入口/共享模块源码快照、`config.json` 和最佳权重。
- 配置快照记录 manifest SHA-256、fold、增强参数、S1/S2 AUC、Git commit 和工作区状态。

5折结束后使用 `summarize_cv_results.py` 合并每位患者仅一次的测试预测，报告 pooled OOF AUC 与患者级 bootstrap 95% CI；使用 `compare_cv_models.py` 对同一批患者进行配对比较。

患者概率固定为患者内图片癌概率均值。阈值 0.5 仅用于训练结束时的初始描述；临床阈值仍须在验证集选择，然后在测试集锁定评估。

## 5. 调试验收

- 严格集 fold 0 DataLoader：训练增强随机、验证增强确定，张量均为有限的 `[N,3,224,224]`。
- ResNet50 与 EfficientNet-B0 均已使用随机初始化、小样本、S1/S2 各 1 epoch 跑通。
- smoke test 指标没有统计意义，仅证明读取、训练、阶段选择、预测、分层输出和保存链路完整。
