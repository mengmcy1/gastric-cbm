# 研究结果摘要

本目录只保存经过隐私审计的聚合研究结果，可进入私有 GitHub 仓库。

允许收录：

- 不含患者标识的总体指标和概念簇级统计；
- 不含胃镜图像的汇总图；
- 不含内嵌患者图片的说明文档；
- 对应文件的SHA256清单。

禁止收录患者级/图片级预测、原始路径、典型病例、候选区域、热图、特征缓存及任何
可回溯患者的数据。完整结果仍只保留在服务器受控目录。
