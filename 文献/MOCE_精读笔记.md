## 一句话总结

**MOCE 完全基于模型自身内部计算（梯度+激活）来发现和评估"概念"，不依赖任何人类标注或外部分割方法，因此提取的概念忠实反映模型自身的视角，而不是人类认为模型应该关注的视角。**

---

## 动机：为什么现有方法不够？

| 方法 | 依赖 | 问题 |
|------|------|------|
| Grad-CAM | 无 | 只给热图，"看哪里"但不知道"看什么" |
| Network Dissection | Broden 标注数据集 | 受限于人类预定义的 1197 个概念标签 |
| TCAV | 随机图像作为负样本 | 概念向量方向对随机图像选择敏感 |
| ACE | SLIC 超像素分割 | 不同模型产生**相同形状**的片段——说明 SLIC 在主导，模型自身视角被掩盖 |

MOCE 的核心论点：**对模型的解释应该忠实于模型本身。**

## 方法总览

```
┌─────────────────────────────────────────────────┐
│  阶段 A：概念提取（Concept Extraction）            │
│                                                   │
│  同类图像 → 前向+反向 → 筛选激活图 → 二值掩码      │
│  → 连通分量 → 去冗余 → 裁剪 → 再编码 → 聚类        │
│                                         ↓         │
│                                  25 个"概念"      │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│  阶段 B：概念评估（Concept Evaluation）            │
│                                                   │
│  移除概念 → 置信度下降 = 移除分数 SR               │
│  仅保留概念 → 置信度 = 保留分数 SE                 │
│         ↓                                         │
│   每个概念的重要性排序                              │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│  阶段 C：泛化到新图像                               │
│                                                   │
│  新图像 → 同流程生成裁剪部分 → 最近邻匹配已有概念     │
│  → 显示该图像激活了哪些概念                          │
└─────────────────────────────────────────────────┘
```

## 阶段 A 详细步骤

### A1. 激活图筛选（减少计算量）

对类别 \(l\) 的图像集，在第 \(j\) 层卷积得到激活图 \(S_i \in \mathbb{R}^{D' \times H' \times W'}\)（D' 个通道）。

对每个通道 \(d\) 计算重要性：

\[
g_{i,d} = \frac{1}{H'W'} \sum_{h,w} \frac{\partial y_l}{\partial S^{i,d}_{h,w}}, \quad
a_{i,d} = \frac{1}{H'W'} \sum_{h,w} S^{i,d}_{h,w}
\]

\[
L_{i,d} = \text{ReLU}(g_{i,d} \cdot a_{i,d})
\]

- \(g_{i,d}\)：梯度 GAP — 该通道对目标类别的敏感度
- \(a_{i,d}\)：激活 GAP — 该通道的平均激活强度
- \(L_{i,d}\)：综合重要性 — 梯度×激活，ReLU 只保留正向贡献

**保留 \(L_{i,d}\) 最高的 50% 通道。**

### A2. 生成二值掩码

对每个保留的激活图：
1. 上采样到原图尺寸 (H × W)
2. 取 **top γ%** 高激活区域（默认 γ=10%），设为 1，其余为 0

→ 得到二值掩码 \(b_{i,d} \in \{0,1\}^{H \times W}\)

**γ=10% 的含义**：每个掩码只标出图像中最活跃的 10% 区域，保证概念是局部、具体的。

### A3. 连通分量 + 去冗余

**问题**：掩码数量 = 保留通道数（仍然很多），且可能存在多焦点（一个掩码覆盖多个不连通区域）。

**步骤 ① — 单连通分量保留**：
- 取每个掩码的**最大连通分量**
- 若最大连通分量面积 < 图像总面积的 0.5%，丢弃该掩码

**步骤 ② — 贪心去冗余**（Jaccard 相似度）：
- 按 \(L_{i,d}\) 从高到低排序
- 对候选掩码，计算与已选掩码的 Overlap：\(O_p = \frac{|b \cap m_p|}{|b \cup m_p|}\)
- 若对所有已选掩码都有 \(O_p < 0.5\)，则加入（视为独特掩码）

→ 最终得到去重后的掩码集合 \(M_i = \{m_1, m_2, ..., m_P\}\)，通常 P ≪ D'

### A4. 裁剪 + 再编码

用每个掩码裁剪原图：\(x_{i,p} = x_i \odot m_p\)

裁剪后放大到模型输入尺寸（保持宽高比），再次前向传播，在**同一层 j** 做 GAP：

\[
v_{i,p} = \text{GAP}(f_j(X_{i,p})) \in \mathbb{R}^{D'}
\]

**关键**：\(v_{i,p}\) 是模型对"仅看到该裁剪区域"时的特征编码，纯内部视角。

### A5. K-Means 聚类

将所有图像的所有裁剪部分的特征向量 \(\{v_{i,p}\}\) 聚为 **k=25 个簇**（欧氏距离 + K-Means）。

**每个簇 = 一个"模型导向的概念"**，包含语义相似的图像区域。

## 阶段 B 详细步骤

### B1. 两种图像变体

对图像 \(x_i\) 和概念 \(h\)（包含若干掩码对应的裁剪区域）：

- **移除图像** \(R_h(x_i)\)：从 \(x_i\) 中删除概念 h 覆盖的所有像素
- **保留图像** \(E_h(x_i)\)：仅保留概念 h 覆盖的像素，其余涂黑

### B2. 评分

**移除分数**（越高 = 越重要）：
\[
SR_h(x_i) = \frac{f_l(x_i) - f_l(R_h(x_i))}{\sum_{c=1}^{k} [f_l(x_i) - f_l(R_c(x_i))]}
\]

**保留分数**（越高 = 该概念单独就能支撑预测）：
\[
SE_h(x_i) = \frac{f_l(E_h(x_i))}{\sum_{c=1}^{k} f_l(E_c(x_i))}
\]

其中 \(f_l(\cdot)\) = 模型对真实类别 \(l\) 的 softmax 输出概率。

### B3. 全局重要性聚合

\[
S_h = \frac{1}{k} \sum_{i=1}^{n} \left[ \alpha \cdot \chi_R(1 - SR_h(x_i)) + \beta \cdot \chi_E(1 - SE_h(x_i)) \right]
\]

其中 \(\chi\) = 排名函数（值越小排名越靠前），\(\alpha=1.0, \beta=0.5\)。

→ 最终得到 **k 个概念的全局重要性排序**。

---

## 核心超参数

| 参数 | 默认值 | 作用 |
|------|--------|------|
| k | 25 | 聚类数（概念数量） |
| γ | 10% | 掩码二值化阈值（越小概念越细粒度） |
| α | 1.0 | 移除分数权重 |
| β | 0.5 | 保留分数权重 |
| 目标层 | 最后一层 CNN（flatten 前） | 特征提取层 |

## 实验关键发现

1. **架构差异可视化**：VGG19 → 细长条带状概念，InceptionV3 → 圆角矩形细粒度概念，ResNet50 → 介于中间。不同架构确实在"看"不同的东西。
2. **层级概念变化**：浅层 → 边缘/纹理，深层 → 完整物体部件
3. **人类评估**：入侵者检测 96.18%，有意义性 92.05% → 概念是可理解和语言描述的
4. **重要性验证**：添加 top-5 概念 → 准确率提升最大；移除 top-5 概念 → 准确率下降最大
5. **超参数鲁棒性**：α, β 不敏感；γ 影响显著（5% = 眼睛级别，25% = 脸部级别）

## MOCE 的优势

- ✅ **纯模型视角** — 不依赖任何外部因素
- ✅ **局部概念** — 不是整图热图，而是具体的图像区域
- ✅ **模型不可知** — 适用于任意 CNN + 任意数据集
- ✅ **可泛化** — 新图像可以匹配到已有概念
- ✅ **重要性可量化** — 每个概念有用移除/保留实验得出的分数

## MOCE 的局限

- ⚠️ 不能捕获配对概念（如两只眼睛算两个簇，缺少"眼睛对"这一层次）
- ⚠️ γ 需要人工调节，不同任务最佳值不同
- ⚠️ 浅层网络（2-3 层）不适用
- ⚠️ 小分辨率数据集（如 CIFAR-10）效果差
