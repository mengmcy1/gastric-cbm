> **论文**: What Does a Model Really Look at? Extracting Model-Oriented Concepts for Explaining DNNs
> **出处**: Kim & Chae, TPAMI 2024, 46(7):4612-4624 ｜ **代码**: https://github.com/DILAB-HYU/MOCE
> （本文件是逐段带读后的浓缩版，详细逐段笔记见 `MOCE_精读笔记.md`）

---

## 一句话核心

**MOCE 只用一个已训练好的冻结 CNN 自身的「梯度 + 激活」来发现并评估"概念"，不依赖任何人工标注(Broden)或分割(SLIC)，因此还原的是「模型真正在看什么」，而非人类视角。**

三大对手死穴：Broden 派(ND/TCAV/IBD)靠人标→有偏见+漏标；ACE 靠 SLIC 分割→抹掉模型差异；Distillation/ConceptSHAP 靠代理模型/额外网络→本身又是黑箱。

---

## 完整算法流程

```
                被解释模型（训练好、参数冻结，全程唯一模型）
─────────────────────────────────────────────────────────────
【提取 III-A】
 原图 x_i ──前向──> 第j层 D′个通道特征图 S_i
   │
   ├─(1)(2)(3) 通道重要性  L_{i,d}=ReLU(g·a)   g=梯度(多重要) a=GAP(多活跃)
   │           按 L 排序，丢掉不重要的一半通道（省3×算力）
   │
   ├─ 每个留下通道的特征图 → 上采样 → top γ%(10%)置1二值化 → 掩码 b_{i,d}
   │
   ├─ 连通域分析：一张掩码只留最大连通块（<0.5%整张丢）→ 保证“一掩码一概念”
   │
   ├─ 去冗余(公式4 Jaccard/IoU)：与已选掩码 IoU≥1/2 判为冗余丢弃 → 得干净掩码集 M_i
   │
   ├─ 抠图块 x_{i,p}=x_i⊙m_p → 等比上采样 → 再过模型取GAP → 特征向量 v_{i,p}
   │
   └─ 对全类所有向量 k-means 聚成 k=25 簇 →【一个簇 = 一个概念】

【评估 III-B】给每个概念打重要性分（纯前向，不训分类器，替代TCAV）
   S^R(公式5) 移除概念h(涂黑)看类别概率跌多少   → 必要性
   S^E(公式6) 只留概念h看模型多自信            → 充分性
   S_h(公式7) 两者转排名，α/β 加权、全类平均    → 概念重要性

【迁移 III-C】新图：抠块取向量 → L2 最近邻塞进已建好的25簇（1-NN，不重聚类）
   → 输出：top-k关注区域 + 所属概念簇 + 最近邻patch，可解释对/错预测(Fig.7)
```

## 超参速查表（复现直接抄）

| 超参 | 默认 | 作用 / 影响 |
|------|------|-----------|
| k（簇数=概念数/类） | **25** | 沿用 ACE |
| γ（二值化比例） | **10%** | 概念粒度：小→细(眼睛)，大→粗(整张脸) |
| α, β（公式7权重） | **1.0 / 0.5** | 移除项权重更高；β≥α 时 VGG 概念易难懂 |
| 提取层 | **最后一个卷积层**（Flatten前） | 高层语义最强；也支持任意层 |
| 聚类/距离 | k-means / 欧氏距离 | 建库 k-means；新图用 L2 最近邻 |

## 实验结论（IV）

- **定性**：跨模型视角差异(VGG细长/Inception圆角细节/ResNet居中)、跨层语义(浅层边缘→深层语义)、新图迁移+对错解释。
- **对比**：抓到 Broden 没有的"猫须"(证明人标漏概念)；比 ACE 不受分割束缚、比 Distillation 指向目标图本身、比 Grad-CAM 更细粒度(概念部件 vs 整体热图)。
- **三大量化实验**（= 引言贡献3的兑现）：
  | 轴 | 方法 | 结果 |
  |----|------|------|
  | Coherency 一致性 | 找茬 intruder | **96.18%** |
  | Meaningfulness 有意义性 | 二选一+文字描述 | **92.05% / 75.11%用词一致** |
  | Importance 重要性 | **SSC/SDC** 增删top-5概念看精度 | MOCE 冲击最大 |

---

## 三大局限（V）

1. **超参需人在环**：概念质量评价主观，无法全自动定 γ/α/β。
2. **依赖深模型 + 大数据**：浅网(2~3层)或小数据集 → 可视化分辨率低、概念重叠（CIFAR10+ResNet20 已见此问题）。⚠️ 对本项目关键。
3. **单连通分量**：成对部件(双眼/双耳)只能抓一个；拟用概念层级(eye→eyes→face)缓解。

## 对胃早癌 CBM 项目的落地映射（路线 A）

| 立项书要素 | MOCE 对应 |
|-----------|-----------|
| 路线A：概念发现 | 特征图→掩码→连通域→去冗余→聚类，k=25簇 |
| 概念交专家命名（癌/非癌/伪相关） | 25 个簇的 top-k patch → 内镜专家命名 |
| 目标五·解释忠实性(deletion/insertion, top-k ablation) | **S^R/S^E 与 SSC/SDC 就是概念版 insertion/deletion**，可直接照搬 |
| 目标五·合理性(命名一致率/Likert/κ) | Coherency 找茬 + Meaningfulness 描述测试可改造 |
| 意义4·发现新标志物 | "猫须不在Broden"→ 模型导向能发现人类没定义的特征 |
| 意义3/目标五·人类干预 | 关掉伪相关概念(涂黑/移除)再看性能变化 |

⚠️ **风险预警**：本项目数据(~3314张)远小于 ImageNet，触及局限②——MOCE 概念可能出现**分辨率低/概念重叠**。复现时考虑更强 backbone、迁移学习、数据增强；γ/α/β 需结合内镜专家判断调，无法纯自动。
