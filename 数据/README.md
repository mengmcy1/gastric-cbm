# 数据目录说明

## 当前使用

- `第二批裁剪后_v1_1`：分类器去偏重训练与既有A/A0/B/C/D实验使用。
- `第二批整理后`：第二批预处理追溯、当前批量推理和Grad-CAM仍使用。
- `胃早癌概念提取训练集_裁剪后_v1_1`：当前MOCE严格平衡概念集使用。
- `胃镜多中心测试集`：独立多中心癌/非癌外部测试。

## 归档

- `归档/原始数据_只读`：第一批、第二批原始数据、视频和医学生整理概念集原图。
- `归档/历史裁剪版本`：已被v1.1替代的完整裁剪版本。
- `归档/调试输出`：预处理debug产生的小规模图片副本。

归档文件均保留，没有删除。原始概念集移动后，相关审计和冻结清单中的
`original_path` 已同步更新；当前训练、MOCE和外部测试均读取顶层正式数据。
