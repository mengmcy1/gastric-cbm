# RP-C1 Residual-Preserving Anchor Effect Screen

## 一、目的

RP-B 回答了 Anchor 与癌/非癌、数据来源之间的关联。RP-C1 进一步回答：

> 如果从 C-long 内部删除某个 Anchor 对应的 SAE Feature，模型的癌/非癌决策会改变多少？

本阶段是 development train-only 的技术 effect screen，不产生显著性 PASS/FAIL，不读取 val、internal test 或 external，不等待医学命名。

## 二、干预方法

每个 Anchor 在 seed42、43、44 中各对应一个 Feature，三个 seed 分开干预，不平均 activation 或 decoder。对图像每个7×7位置：

```text
x' = x + (alpha - 1) * h_j * d_j
alpha = 0
```

即删除该位置上 Feature `j` 的 decoder component，但保留 SAE 未解释的 residual。一张图的49个位置全部处理，不只删最强位置。修改后重新计算：

```text
attention -> attention pooling -> frozen classifier -> logits/probability
```

因此测得的是 Feature 删除后的总决策效应，允许模型的关注位置同时改变。

## 三、指标语义

主指标固定为：

```text
delta_margin = margin_ablated - margin_original
```

- 癌患者 `delta_margin < 0`：Feature 原本支持癌侧判断。
- 非癌患者 `delta_margin > 0`：Feature 原本支持非癌侧判断。
- `label_support=(2y-1)*(margin_original-margin_ablated)`：无论类别，大于0都表示 Feature 帮助模型朝真实标签方向判断。
- `delta_D=mean_noncancer_delta_margin-mean_cancer_delta_margin`：大于0表示删除后癌/非癌 margin 分离缩小。

`delta_probability` 为次指标；prediction flip 只是冻结阈值下的描述性结果。Attention 轻量记录 cosine、L1总变化和 peak 位置是否改变。

聚合顺序为：

```text
image -> patient内均值 -> patient等权label组
```

同时报告所有患者的 population effect 和仅 Feature 真正激活患者的 conditional effect。

## 四、三 seed 汇总

所有 seed-level 结果完整保留。Anchor 级效应大小用三 seed 中位数汇总，并单独记录癌与非癌效应方向是 3/3、2/3 还是更低一致。禁止把患者和 seed 直接池化后只保留一个平均数。

## 五、RP-C2 入选规则

下列规则在 RP-C1 结果产生前冻结，不构造加权总分：

1. 全体患者平均绝对 `delta_margin` 的 Top 5%，固定58个。
2. `delta_D` Top 5%，固定58个。
3. 198个 source-risk Anchor 内总效应 Top 25%，按实际数量向上取整。
4. 10个 source-sensitivity changed Anchor 全部保留。
5. 所有 v1 `cancer_enriched` Anchor 保留。
6. 总效应最低20个作为技术负对照；除非同时进入前五轨，否则不是 RP-C2 candidate。

指标并列时按 Anchor ID 升序确定固定数量。RP-C2 入选是上述前五轨的并集。

## 六、实现验收

- 纯函数回归测试：7/7通过。
- CPU debug：16图、8 Anchor、3 seed、癌/非癌均覆盖，通过。
- CUDA debug：64图、64 Anchor、3 seed，五级 identity 全通过；最大误差不超过 `4.77e-7`。
- CUDA 工程基准：512图、256 Anchor、3 seed总耑时11.9秒；正式任务估计2–5分钟。
- 批量优化公式与逐 Anchor 显式构造 `x'` 的单元测试一致。
