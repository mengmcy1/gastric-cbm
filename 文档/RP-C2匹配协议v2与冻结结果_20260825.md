# RP-C2 deterministic nearest-control matching v2（2026-08-25）

## 1. 与 v1 的关系

v1 outcome-blind feasibility audit 的正式状态继续保留为：

```text
matching_calibration_infeasible
```

失败对象是“最大 caliper 0.15 且每个 target-seed 必须统一拥有100个 controls”的数量要求，不是 RP-C2 科学假设失败，也不是三变量匹配空间整体失效。

v2 在任何 RP-C2 intervention outcome 产生前，根据 v1 的纯匹配几何结果冻结。v2 不修改 active frequency、activation mass、representation energy、percentile 变换或 `L-infinity` 距离，只把 control 选择改为确定性的 nearest-first，并允许稀有几何对象使用20至99个 controls。

## 2. 冻结匹配定义

每个 SAE seed 独立执行：

1. 在完整冻结 eligible Feature universe 上，对 patient-equal mean active frequency、activation mass、representation energy 分别计算 average-midrank percentile；
2. 从 control universe 排除149个唯一 study-object Feature ID；
3. target 与 control 的距离为三个 percentile 差异的最大值；
4. 仅保留距离 `<=0.15` 的候选；
5. 按 `distance ascending -> Feature ID ascending` 排序；
6. 候选数至少100时取最近100个；
7. 候选数为20至99时取 caliper 内全部候选；
8. 少于20时记 `matching_support_insufficient`；
9. 禁止运行时扩大 caliper、补选 study object 或重新匹配；
10. 同一 target 内 control 不重复，不同 target 之间允许复用。

该规则不使用 RNG，完全确定性。average-midrank percentile 在数学上是
`1/(2N_eligible)` 的离散值；正式实现使用二倍 midrank 的整数差计算
`L-infinity` 距离，再除以 `2N_eligible` 输出距离。数学并列不得被浮点舍入拆开。

## 3. Study-object 多角色边界

冻结角色旗标为：

- primary candidate：122；
- low-effect control：20；
- post-RP-C1 secondary exploratory：8；
- 唯一 study objects：149。

`a00987` 同时带 primary 与 low-effect 两个旗标。它进入122主候选分母，也进入20个 low-effect 描述性分组；两个集合不构成独立样本组，禁止把二者用于独立组假设检验。low-effect controls 由 RP-C1 结果选择，只是 descriptive negative controls，不是 null calibration population。

## 4. 实现验收修订

第一次生成的 `matching_v2_freeze/` 在深度验收时发现：两个数学上相同的
midrank 距离因浮点减法出现约 `3e-17` 差异，未进入 Feature ID tie-break。
该目录在任何 intervention 前判为 implementation failure，永久保留且不得作为
RP-C2 输入。修复未改变匹配变量、caliper、control数量或统计定义，只把协议隐含的
有理数距离改为整数 doubled-rank units 显式实现。正式冻结产物写入新的
`matching_v2_freeze_rational_ties/` 目录。

- matched-control manifest 总行数：44424；
- `matching_support_insufficient`：0；
- 所有 study objects 均被保留；
- 没有扩大0.15 caliper；
- 没有抽样随机性；
- 没有运行模型或计算干预结果。

五个不足100的对象仍对应 v1 已记录的稀有匹配几何。它们的 matched-control percentile 和条件经验尾部概率必须按实际 `N_control` 计算，并同时报告：

```text
n_control
percentile_resolution = 1 / n_control
conditional_p_resolution = 1 / (n_control + 1)
conditional_exploratory = true
selected_on_same_train_data = true
```

条件经验量只能描述 target 在 matched reference set 中的位置，不构成未经选择偏倚校正的确认性显著性检验。

## 7. 当前状态与下一步

当前只完成 matching 子协议冻结，并不表示整个 RP-C2 protocol 已冻结，也不允许立即启动正式干预。下一步仍需关闭：

1. 中间剂量 curve-overall 与 curve-separation 的精确统计实现；
2. 每个 seed 的 matched-control summary 和 anchor-level 三 seed汇总；
3. endpoint reproduction、alpha=1 identity 和固定 attention 诊断 schema；
4. source `N>=15` 描述性输出；
5. 122/20/8 三类角色的汇总边界；
6. 小规模 probe 与正式运行完整性规则。
