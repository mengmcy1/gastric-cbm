# RP-B Anchor 技术分析（2026-08-25）

## 一、阶段定位

RP-B 不负责医学命名，也不等待医生对图片进行审核。本阶段只使用 RP-A development 产生的 1150 个 strict anchor，完成可重复的技术属性分析、来源风险审计、技术家族构建和后续处理优先级划分。

技术属性不等于医学语义：`shared_high` 仅表示某个 Anchor 在癌与非癌患者中都有较高覆盖，`technical family` 仅表示多项模型内部证据一致。是否对应肿瘤、炎症、反光、器械或其他医学概念，由后续医学审核独立完成，不反向修改 RP-B 技术筛选规则。

## 二、冻结规则

### 2.1 Sharedness

每个 Anchor 分别计算癌与非癌患者的 presence、activation mass、ranking、representation energy 和 label AUC。Sharedness 通过 1000 次**按 label 分层**的患者有放回 bootstrap 评估，随机数生成器固定为 `PCG64(20260825)`。这与冻结协议的 `stratified_by_label_with_replacement` 及实际代码一致；本文首版误写为 `label × source`，本次已更正。

- coverage 绝对等价界值：0.10；
- mass 对比指标等价界值：0.10；
- `shared_high` 要求癌和非癌两侧患者覆盖均不低于 0.25；
- 分类要求 3 个 seed 中至少 2 个一致，且不存在相反 seed；
- AUC 同时报告 DeLong 置信区间，但不用“AUC 接近 0.5”替代两侧等价判定。

最终技术分类为 `cancer_enriched`、`noncancer_enriched`、`shared_high`、`shared_low_rare` 和 `mixed_uncertain`。

### 2.2 Source audit

在癌和非癌内分别检验 Feature 与数据来源的关联：presence 使用卡方检验，mass 使用 Kruskal-Wallis 检验，并用 BH-FDR `q=0.05` 校正。只有同时具备统计显著性和预先冻结的实际影响规模，且 2/3 seed 一致，才标记 `source_risk`。该标记是审计旗标，不自动删除 Anchor。

### 2.3 Technical family

两个 Anchor 只在以下技术证据达到冻结门槛时才建立 family edge：

- decoder cosine ≥ 0.90；
- union-positive 患者行为 Spearman ≥ 0.85；
- Top-25 患者 Jaccard ≥ 0.40；
- patient-balanced spatial similarity ≥ 0.75，有效患者数不少于 25；
- 上述关系在 3 个 seed 中至少 2 个成立。

家族使用确定性 complete-link 规则构建，不使用医学标签。家族代表按稳定性、患者覆盖、representation energy、Anchor ID 的词典序确定，不构造人工加权总分。

- Anchor 总数：1150；
- seed 级统计：3450 行；
- source audit：6900 行；
- matching evidence：6900 行；
- `shared_high`：331；
- `cancer_enriched`：1；

- `noncancer_enriched`：0；
- `shared_low_rare`：0。

唯一的 `cancer_enriched` Anchor 为 `a00987`，但同时被标记为 `source_risk`，因此不能直接解释为肿瘤特异医学概念。

1150 个 Anchor 的患者覆盖普遍较高：中位数为 1.0，5% 分位数约为 0.9979，最低约为 0.2913。这说明当前 Anchor 更像在广泛被模型使用的视觉基元中区分行为差异，而不是大量仅在少数病例出现的稀有概念。

### 3.2 Source risk

- `source_risk`：198；
- `content_candidate`：952。

Source risk 只表示 Anchor 的激活与数据来源有稳定关联，不等于该 Anchor 必然是伪特征。这 198 个 Anchor 应在后续图片导出和干预中单独展示，方便医学团队判断是真实临床差异还是数据偏差。

### 3.3 Technical family

在冻结的 decoder cosine 预筛门槛下，符合“至少 2/3 seed 的 cosine ≥ 0.90”的 Anchor pair 为 0，因此：

- technical family 数：1150；
- 每个 family 均为 singleton；
- family edge 数：0；
- technical-family member 轨道：0。

这不是程序失败。不同 Anchor pair 的跨 seed 第二高 decoder cosine 最大值仅约 0.2497，99.9% 分位数约 0.0468，与 0.90 门槛相差很远。因此本轮没有事后降低门槛。技术上应把 1150 个 Anchor 作为 1150 个独立且跨 seed 稳定的解释单元继续处理。

### 3.4 后续优先级轨道

- `content_candidate`：952；
- `source_risk`：198；
- `rare`：0；
- `technical_family_member`：0。

各轨道内只使用冻结的词典序排序：稳定性、患者覆盖、representation energy、Anchor ID。不用加权总分把不同含义的证据混成一个数字。

### 3.5 Sharedness 分层口径复审

RP-B v1 冻结协议和实际代码均按 label 分层 bootstrap，因此上述 331/1/818 是可复现的 v1 正式技术分类。为评估 source 构成波动的影响，另外执行了一次不参与分类、不覆盖 v1 结果的 `label × source` 六层敏感性复算。

敏感性口径下：

- `shared_high`：327；
- `cancer_enriched`：1；
- `mixed_uncertain`：822；
- 类别改变：10/1150（0.87%）；
- 7 个从 `shared_high` 转为 `mixed_uncertain`，3 个反向转换；
- 唯一的 `cancer_enriched` Anchor 未变。

这说明 source 分层会影响少数边界 Anchor 的置信区间，但不改变 RP-B 的主体结论。为保持预先冻结语义，v1 分类不被六层诊断替换；后续 RP-C 将同时保留 v1 class、source-risk 和敏感性变化标记。

`mixed_uncertain` 不表示 Feature 无用或不可解释。它只表示该 Anchor 没有同时满足其他四类的严格双指标、跨 seed 规则。诊断表另行保留 coverage、mass 和 seed 一致性的原因码，供 RP-C effect screening 分层使用，但不改变冻结的五类分类。

原 v1 口径的 818 个 `mixed_uncertain` 中，806 个的原因码为 `coverage_equivalent_mass_not_equivalent`，即患者层面“是否出现”已在癌/非癌间等价，但激活强度未达等价条件；其余 12 个为 `within_seed_joint_criteria_unresolved`。因此 `mixed_uncertain` 的主要含义不是“Feature 没用”，而是 presence 指标已较粗，需要在 RP-C 重点考察 mass、spatial 和 residual-preserving intervention。

## 四、阶段结论

1. RP-B 已完成 1150 个 Anchor 的技术属性表、癌/非癌共享性分类、来源审计和技术家族构建。
2. 数据明确证明癌与非癌之间存在大量共享的模型特征：331 个 Anchor 被分为 `shared_high`。这支持后续同时展示癌与非癌的高激活图，而不把所有 Feature 强行解释为癌特异概念。
3. 198 个 Anchor 具有稳定的来源关联，需在后续技术交付中单独标记，但不应在没有图像和干预证据时直接删除。
4. 本轮没有找到可以合并的 technical family；后续不需要进行 family-level intervention，而是直接对独立 Anchor 做轻量干预和图像证据导出。
5. 这些结果是 development train-only 技术分析，不代表正式 RP-A 已完成，也不代表医学概念已被确认。val、internal test 和 external 均未读取。

RP-B 已于 2026-08-25 正式收口。后续医学命名不阻塞技术流程，但也不能回改本阶段的sharedness、source-risk、sensitivity和technical-family结果。

## 五、下一步

1. 对全部 1150 个 Anchor 完成一次 residual-preserving `100% → 0%` 轻量消融，记录患者级 `delta margin`、`delta probability` 和癌/非癌分层效应。
2. 为全部 Anchor 导出高、中、低、零激活样本和 hard negatives，并对 198 个 `source_risk` Anchor 提供来源分层图像。
3. 仅对轻量干预筛出的高影响 Anchor、source-risk Anchor 和后续需要细查的代表 Anchor，进行 `100%/75%/50%/25%/0%` 五档干预、matched random controls 和 attention 变化分解。
4. 技术团队交付 Technical Feature Atlas 后，医学团队再独立完成命名、artifact 判定和临床解释；医学审核不回改本阶段已冻结的 sharedness、source risk 和 technical-family 规则。
