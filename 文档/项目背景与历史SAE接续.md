# 项目背景、阅读顺序与历史SAE接续

## 当前在解决什么问题

临床任务是白光胃镜图像的早癌／高级别瘤变与非癌分类。非癌不等于正常：可包含外观可疑的良性改变。
研究不只要求分类，还希望说明模型看哪里、哪些内部模式影响预测、这些模式能否由医生解释。
数据按患者划分，图像预处理采用Keep口径；输入模型前裁边及FOV处理，不能把原始截图直接当作正式输入。

第一步是局部灰度教师指导全图彩色学生。局部教师获得病灶附近的裁图并接受癌框注意力监督，
学生训练时学习教师输出及空间关注，使用时只看整张图。灰度局部输入是研究设计，不代表已经证明完全去除颜色或背景捷径。
原MAGE论文使用像素级mask，而本项目使用扩边矩形ROI及癌图矩形框，非癌原先使用困难ROI；这是适配而非逐项复现。

第二步冻结C-long，用RA-SAE分析其最终7×7×1280表示。早期纯SAE替换没有同时保持足够重构和分类保真，
所以当前定位改为保留原分类器及residual的事后分析。采用原100轮、2560项RA-SAE；
不是旧文档里的pooled SAE、10240宽度S2c，亦不是后来的标准化或200轮候选。

解释分三个层次：激活表示Feature出现了多少；梯度筛选与实际删除评价模型内部功能；医学命名需要跨病例人工证据。
三者不能替代：高激活不必然支持癌，功能重要不保证含义单一，能形成技术聚类不代表Concept Family成立。
医学反馈发现混杂，因此Family、CBM、辅助阅片验证尚未完成。Leiden响应实例分组仍是设想。

## 历史RA训练需要的额外准备

这里只用于接续历史研究；当前SAE推理不需要这些依赖，也不要为单图推理安装整套历史环境。
历史分支在单独目录取得后，安装主README环境，并额外安装：

```bash
python -m pip install ultralytics==8.4.118
```

原因是原SAE损失模块经历史工具导入Ultralytics，即使此次不运行检测器也需要该依赖。
不要把缺少该依赖误诊为权重损坏；目前新推理入口没有这条依赖链。

在研究工作副本根目录解包原受控补充包和审查增补包；图片数据仍使用已经交接的受控数据目录。
默认位置仍为`数据/教师学生模型交接数据`。原100轮所需关键路径为：

- `结果/SAE/CLong_S2b结构重构_20260820/frozen_spatial_cache/`：train/val元数据、空间表示、pooled表示和注意力；
- `结果/SAE/CLong_S2c_Matryoshka_20260821/gamma_pool_calibration_seed42.json`：原损失系数；
- `结果/SAE/RA_SAE_Pilot_20260908/pilot_unique_step/`：原20轮轨迹、初始化信息及检查所需权重；
- `结果/MAGE/MG2L训练轮数敏感性_20260818/mg2l_attention_sae_summary_seed42.json`：原C-long选择摘要；
- `结果/MAGE/MG2L训练轮数敏感性_20260818/正式验证集筛选/mg2l_armc_efficientnet_b0_seed42/mg2_armc_best_student.pth`：原C-long权重。

**原pilot直接读取摘要的`selected_checkpoint`绝对路径。** 在新机器的研究工作副本中，将该字段
设为上面原权重在当前克隆根目录下的实际绝对路径。不要修改归档原件、权重内容或SHA字段；
不能让脚本无意读取原作者工作区。其他旧入口如读取`checkpoint`／`run_dir`等绝对路径，也需按其实际输入逐项核对，
不对所有JSON做盲目全局替换。图片旧路径通过主分支`manage_mage_handoff.py restore-data`机制恢复。

原100轮对应的参数是：

```text
run_clong_rasae_pilot.py --epochs 100 --initialization unique --match-encoder-scale
```

完整运行还需指定`--device`及一个不存在的`--output`目录，并设置
`PYTHONPATH="$PWD/程序/MAGE/正式代码:$PWD/程序/模型训练/正式代码:$PWD/程序/SAE/正式代码"`。
以上列的是研究参数，不是本轮授权启动全量训练的命令。GPU任务先检查资源；脚本不是正式任务的自动后台调度器。
`--debug`会缩小数据和模型，不能与原100轮参数或结果混称。100轮入口从头训练并比较前20轮轨迹，
不是从100轮checkpoint继续；全新软件环境可能引起数值轨迹差异，不得放宽原校验来冒称精确复现。

## 可以承诺到哪里

独立审查已验证当前推理、新教师／学生小样本训练和SAE功能输出；原RA参数化权重也能进行一次真实梯度更新。
原RA／MG1b／C-long发布的研究checkpoint没有精确续训所需的完整优化器和随机状态。
因此“接着研究或另起微调”可行，“精确延续原训练轨迹”不能承诺。没有必要为离岗交接临时扩建新的训练框架。

## 医学反馈的追溯边界

首批8项Feature的64个配对、后续候选Family对照和最新20项展示各是不同批次，按各自原图与内部索引查看。
最新相对轮廓不能替代旧0.5×train Q99展示版本。审查增补包保存能找到的原发送ZIP及原PNG，未重新生成图片。
早期79条组级反馈缺少部分原图代号，无法唯一定位的反例仍是不可追溯的初步意见；不能因找到原图册就提升证据等级。
