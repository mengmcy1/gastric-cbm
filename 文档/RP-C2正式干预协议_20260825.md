# RP-C2 中间剂量与确定性匹配参考干预协议（2026-08-25）

## 1. 研究问题

RP-C1 已经用完全删除 `alpha=0` 筛查哪些稳定 Anchor 值得进一步研究。RP-C2 不重复把 endpoint 当作新证据，而回答：

> 目标 Feature 在部分削弱时是否持续影响模型决策，并且这种影响是否超过 active frequency、activation mass 和 representation energy 相近的确定性匹配参考 Feature？

本阶段仍是 development train-only conditional exploratory analysis，不产生确认性显著性检验，不进行医学命名。

## 2. 五档干预

`alpha` 表示目标 Feature activation 的保留比例：

```text
alpha = 1.00, 0.75, 0.50, 0.25, 0.00
x' = x + (alpha - 1) * h_j * d_j
```

- `alpha=1`：no-op identity 工程检查；
- `alpha=0`：逐项复现 RP-C1 的工程回归检查；
- `0.75/0.50/0.25`：RP-C2 真正新增的科学数据。

所有 dose-level 基础 effect、图像到患者聚合、癌/非癌和 active-only 口径均复用 RP-C1。任何组合统计都必须先在单个 SAE seed 内计算，再跨 seed 汇总。

## 3. 主统计量

对每个 seed，令 `E(alpha)` 为 RP-C1 同口径的全体患者 overall absolute effect：

```text
intermediate_curve_overall_effect
    = mean(E(0.75), E(0.50), E(0.25))
```

该统计量不使用已经参与 RP-C1 选样的完全删除 endpoint，是 target 与 matched reference controls 的主比较量。

class-separation、癌侧和非癌侧均保留原始 signed effect。预期方向只由 RP-C1 三 seed endpoint 中位数符号冻结；中位数为0时不做方向对齐，不因 RP-C2 结果重新选方向，也不增加 magnitude tolerance。

## 4. 曲线规则性

用 removal strength `r=1-alpha` 与按 RP-C1 方向对齐后的 signed effect 计算五点 Spearman。`rho>=0.9` 只标记 `dose_curve_regular=true`，用于识别只有完全删除才跳变的异常曲线。

该字段是诊断项，不能单独证明 Feature 特异性或机制作用。

## 5. 确定性匹配参考比较

controls 完全继承 matching v2 冻结 manifest，正式 runner 禁止重新匹配。每个 target-seed 报告：

- `n_control`；
- `matched_midrank_percentile`；
- `matched_plus_one_tail_fraction`；
- `effect_ratio_to_control_median`；
- control median、Q90、Q95；
- percentile 与 tail fraction 的分辨率；
- `conditional_exploratory=true`；
- `same_train_selection=true`。

tail fraction 不是 p-value。122个主候选和20个低效对照都由相同 train 的 RP-C1 outcome 选择，存在 selection bias。跨 seed 不合并 tail fraction，只报告三个 seed 原值以及 anchor 层 median/minimum percentile。

effect ratio 只用于非负的 overall 主统计量；control median 为0时输出 null 和 `control_median_zero`，禁止加 epsilon。Q90/Q95 固定用 `numpy.quantile(method="lower")`。

## 6. 角色与汇总

- primary candidate flags：122；
- low-effect control flags：20；
- post-RP-C1 secondary exploratory flags：8；
- unique study objects：149。

`a00987` 同时属于 primary 与 low-effect。三个角色始终作为布尔 flags，主分母为122、low-effect描述分母为20、secondary分母为8。集合不独立，禁止独立两组显著性检验。low-effect controls 不是 null population。

唯一自动技术标签是 `bidirectional_label_supporting_3of3`；其他均为 `mixed_functional_pattern`，不在本阶段新增癌支持强弱阈值。

## 7. Source 与 Attention

source 只作描述性审计。每个 `seed x dose x label x source` 在患者数至少15时报告患者等权 mean/median delta margin；不足15标记 `insufficient_support`。不计算 CI、p 值，也不自动标记 shortcut。

149个 study objects 额外运行固定原 attention 的诊断路径。完整重算 attention 效应减去固定 attention 效应只能称为 `attention_rearrangement_associated_difference`，不能解释为 causal mediation。44424条 matched controls 不运行该诊断路径。

## 8. 工程 Gate

全149对象、三 seed 均执行：

1. `alpha=1`：patch、attention、pooled、logits、probability 五级 identity，继承 RP-A GPU identity tolerance；
2. `alpha=0`：与 RP-C1 已保存 image、patient 和 seed-anchor 产物逐项精确复现。

任一失败属于 implementation failure，禁止产生科学 summary。

中间剂量 probe 固定为：

- `a00139`：覆盖21/27/78 controls；
- `a00987`：多角色且 seed43 为32 controls；
- `a00816`：seed44 为66 controls；
- `a00019`：三个 seed 均为100 controls的最小 Anchor ID。

Probe 只验证工程路径，不进入科学摘要，也不得根据曲线是否“漂亮”修改协议。

## 9. 明确不做

- 不计算经典 p-value 或 BH-FDR；
- 不设置 RP-C2 整体 PASS；
- 不冻结 RP-D Atlas 最终入选标准；
- 不把 low-effect controls 当 null；
- 不把 attention 差异称为中介效应；
- 不读取 val、internal test 或 external；
- 不让医生命名反向影响技术筛选。
