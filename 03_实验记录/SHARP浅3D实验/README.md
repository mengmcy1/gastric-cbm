# SHARP 浅 3D 先导实验

本目录是与既有 `SHARP真实图片测试` 隔离的正式先导实验空间。五张冻结样本及其完整 PLY 副本位于 `01_先导样本/`；原始复现结果不会被覆盖。

变量顺序固定为：完整高斯、无裁剪条件下仅比较运动幅度；再比较单边裁剪；再比较高斯保留率；最后进行性能测试和独立验证。

统计口径：屏幕位移以 P95 为主，P99 与最大值只用于异常诊断。当前高斯投影位移是代理指标，不等同于图像特征光流或固定视角。

目录说明：

- `00_方案与表格/`：冻结清单与环境基线。
- `01_先导样本/`：五张样本的输入图和完整 PLY 副本。
- `scripts/`：实验渲染与指标计算脚本，可随实验包提交并复现。
- `outputs/`：所有本地渲染、视频、深度、Alpha、差异图、指标和性能结果，按阶段分类保存；该目录不提交。
- `02_静止基线/` 至 `10_最终结论/`：保留阶段说明、冻结结论和可提交的小型汇总记录。

本实验包内的脚本不覆盖官方 SHARP 源码；`99_过程文件_可删除或归档/` 仍整体仅本地保留。
