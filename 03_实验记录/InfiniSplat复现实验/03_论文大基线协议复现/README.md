# InfiniSplat 论文大基线协议级复现

## 当前状态

已完成 ETH3D `courtyard` 的首个真实 source-target 大基线样例：

- source：`DSC_0313.JPG`；
- target：`DSC_0317.JPG`；
- 连续序列间隔：4，位于论文所述 10 帧窗口内；
- 真实米制基线：2.587103 m，属于论文 `[2,+∞)` 档；
- 相对旋转：17.327843°；
- 共享 COLMAP 稀疏点代理：63.424%；
- 输出分辨率：2016×1344，与论文 ETH3D 评价尺寸一致。

2026-08-14 随后完成筛选代理下剩余 3 个唯一无向相机对，目前共覆盖全部 4 个通过本地大基线代理门槛的唯一相机对。

本实验是**协议级复现**，不是 Fig. 3/4 精确图片复刻。作者公开仓库没有提供论文使用的 512 对 source-target 清单、Fig. 3/4 帧号或视锥重叠实现。

## 与官方 Demo 轨迹的区别

公开单图 Demo 使用约 0.2～0.3 m 的小幅横移、前后 dolly 和持续 look-at；本目录直接读取 ETH3D COLMAP 的真实源相机与目标相机外参。两者不能混作同一种“大视角实验”。

## 首轮结果

真实目标相机渲染成功。目标帧中：

- `Alpha≥0.5` 覆盖率 50.78%；
- `Alpha≥0.01` 覆盖率 53.38%；
- 硬空洞（`Alpha<0.01`）46.62%；
- 已覆盖区域中的墙面、窗框、砖带和主体边界保持较完整；
- 输入视锥之外的地面、左侧新区域和外边界没有生成式补全。

这一画面形态与论文的技术定位一致：InfiniSplat 的优势是大基线下已有表面组织更连贯，不是生成所有未观测区域。

## 真实端点连续插值视频

为避免只比较 source/target 两张静态图，已在冻结高斯和真实相机端点之间生成 60 帧连续轨迹：

- 相机中心在 source 坐标系中线性插值；
- 旋转使用 SO(3) 最短路径插值；
- 内参在两台真实相机缩放后的参数之间线性插值；
- 第 0 帧为真实 source，相机终帧与冻结 target W2C 的最大绝对误差为 `1.19e-7`；
- 输出 2016×1344、10 FPS、6 秒的黑底/白底 MP4，以及 5 张关键帧、逐帧 Alpha 指标和覆盖曲线。

硬空洞率从起点 0.03% 单调增加到终点 46.62%；在 0.614 m / 4.11° 时首次超过 10%，轨迹中点 1.315 m / 8.81° 时达到 25.91%。这证明空洞不是目标端点的偶发现象，而是单图表示随新显露增加而持续失去覆盖。

该视频用于可视化真实端点之间的覆盖崩塌过程，不是作者公开视频，中间帧也不是 ETH3D 实拍相机。由于平移和旋转同步变化，不能用这条曲线单独归因角度或平移的因果贡献。

## 评价边界

- 论文要求视锥重叠超过 60%，但没有公开精确算法。本地筛选器使用“共享注册稀疏点数 / 两帧较小可见点数”作为明确标注的代理，不能冒充作者指标。
- 论文使用完整 frustum-visible mask。本轮没有该未公开 mask，因此全画面 PSNR/SSIM 只作诊断，不能与论文表格横向比较。
- `target_real_pose_normal_derived.png` 是由高斯最小尺度轴推导的诊断法线，不是作者发布的 Fig. 4 法线渲染器。

## 可复现入口

1. `scripts/select_eth3d_large_baseline_pairs.py`：解析 COLMAP 相机并枚举 10 帧窗口候选；
2. `configs/eth3d_courtyard_dsc0313_source_inference_v1.json`：从 source 图生成冻结高斯；
3. `configs/eth3d_courtyard_dsc0313_to_dsc0317_pair_v1.json`：冻结真实相机对；
4. `scripts/render_frozen_ply_real_target_pose.py`：按真实 target 相机渲染 RGB、Alpha 和派生法线；
5. `scripts/analyze_real_pose_render.py`：计算带有明确非论文口径警告的诊断指标；
6. `scripts/render_real_pose_interpolation_video.py`：在真实相机端点间生成连续黑底/白底视频与逐帧指标；
7. `scripts/analyze_pose_interpolation_video.py`：提取空洞阈值交叉点并生成覆盖曲线。

大型 ETH3D 数据、PLY 和渲染结果位于本目录的 `outputs/`，由 `.gitignore` 排除。
